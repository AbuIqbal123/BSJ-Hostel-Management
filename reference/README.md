# Reference material

These folders are hall materials the contracts were written from. They are not the application. `demo/` is a static page set that can be hosted once for the proposal (for example via `demo/vercel.json`); the other folders are not deployed.

| Folder | What it is |
|---|---|
| `proposal/` | The proposal PDF, the slide deck, and the phone screenshots |
| `demo/` | The workflow pages used to confirm fields and message copy |
| `prototype/` | An earlier clickable draft and its screenshots |

The system in this repository is `backend/`, `mobile/`, and the documents in `docs/`. Start with `docs/database/database.md` and `docs/api/api.md`.
