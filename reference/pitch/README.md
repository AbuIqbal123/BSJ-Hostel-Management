# Pitch

Hall pitch deck and costs estimate. Real phone screenshots from the Expo app.

| File | What |
|---|---|
| `BSJ-Hall-App-Pitch.pptx` | Workflow pitch |
| `BSJ-Hall-App-Costs.pdf` | Build + running cost estimate |
| `phones/` | Framed screenshots |
| `presentation.js` | Rebuild the deck |
| `costs.js` | Rebuild the costs PDF |

```bash
npm install
npm run build
```

Screenshots need a running API, Expo web, and the local shot script (`shot-phones.js`). Do not commit seed passwords.
