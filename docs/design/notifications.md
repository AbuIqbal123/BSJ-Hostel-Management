# Notifications

The resident inbox. Each row is one sentence from this table, then one quieter line with the place and the times. No icons.

`{name}` is the display name of the warden or provost who decided, sent as `decided_by_name`.

| When | Sentence |
|---|---|
| A late-night request is approved | Your late-night request has been approved by {name}. |
| A late-night request is rejected | Your late-night request has been rejected by {name}. |
| A home-going request is approved | Your home-going request has been approved by {name}. |
| A home-going request is rejected | Your home-going request has been rejected by {name}. |

The quieter line is the short place, then the leave and return. Home going uses the dates. Late-night uses the time, then the date. Nothing else is written to this inbox yet.
